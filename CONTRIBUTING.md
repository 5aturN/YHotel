# Участие в разработке

## Рабочий процесс

1. Создайте ветку `feature/<краткое-имя>` от актуальной `develop`.
2. Делайте небольшие коммиты с описанием пользовательского или технического результата.
3. Перед слиянием проверьте тесты, стиль и безопасность:

```powershell
python -m unittest discover -s tests -v
python -m pytest -q
python -m ruff check src tests
python -m bandit -r src/yaotel -ll
pip-audit -r requirements-dev.txt
```

4. Откройте pull request в `develop`; перед выпуском проверенная версия переносится в `main`.

## Данные и секреты

Не коммитьте `.env`, пароли, API-ключи, SMTP-учетные данные и реальные данные гостей. Добавляйте тесты для новых правил бронирования, ошибок API и контроля доступа.
