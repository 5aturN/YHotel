# Руководство гостя

Гость использует HTTP API через интерфейс Swagger по адресу `/docs` или из собственного клиента. Веб-кабинет в текущей версии не предоставляется.

## Поиск номера

Откройте `GET /api/rooms/availability`, задайте дату заезда, дату выезда и число гостей. В ответе перечислены подходящие номера и их вместимость. Поиск не требует аккаунта. Дата выезда должна быть позже даты заезда.

## Создание аккаунта и вход

1. Вызовите `POST /api/auth/register` с email и паролем длиной не менее 12 символов.
2. Вызовите `POST /api/auth/login` с теми же данными.
3. Скопируйте `access_token` из ответа.
4. В Swagger нажмите `Authorize` и введите токен. При использовании собственного клиента передавайте `Authorization: Bearer <token>`.

Пароль не возвращается в ответе. Токен действует ограниченное время; после истечения войдите повторно.

## Бронирование и отмена

После входа вызовите `POST /api/bookings` с идентификатором номера, датами и числом гостей. Успешный ответ содержит номер брони, итоговую стоимость и статус `pending`. Повторное бронирование пересекающихся дат возвращает `409`.

Вызовите `GET /api/bookings`, чтобы увидеть свои брони, или `GET /api/bookings/{booking_id}` для одной записи. `DELETE /api/bookings/{booking_id}` отменяет бронь, но не удаляет историю. Доступ к чужой брони возвращает `403`.

Если для сервиса настроен SMTP, после создания брони на email аккаунта отправляется подтверждение. Отсутствующая SMTP-настройка не мешает бронированию.
